## 💡 Why Mephisto Translate?

Tired of switching tabs to Google Translate while reading documentation, coding in an IDE, or playing games?

**Mephisto Translate** runs silently in your background. Select any text on your screen, trigger the global hotkey, and a sleek modern floating HUD appears right next to your cursor with instant high-accuracy translation.

---

## ✨ Features

- ⚡ **Zero-Distraction Floating HUD:** Displays translations overlaying your active window.
- 🎯 **Global Hotkey & Mouse Hook:** Powered by `pynput` for sub-millisecond shortcut detection.
- 🔄 **Bidirectional History & Tracking:** Automatically remembers recent lookups for easy reference.
- 🎨 **Modern Dark/Light UI:** Crafted with `customtkinter` and country flag assets.
- 🌍 **100+ Languages Supported:** English, Turkish, Spanish, German, French, Japanese, Russian, Chinese, Korean, and more.
- 📋 **1-Click Clipboard Auto-Copy:** Translated text is instantly ready to paste.

## 🚀 Quickstart

### Prerequisites
- Python 3.10 or higher

### Installation
```bash
# 1. Clone repository
git clone https://github.com/jokallame350-lang/translation.git
cd translation

# 2. Install dependencies
pip install -r requirements.txt # or: pip install customtkinter pynput pyperclip pillow

# 3. Launch Mephisto Translate
python main.py
```

---

## ⌨️ How to Use

1. Run `python main.py`.
2. Highlight any text in any application (PDF, Discord, VS Code, Browser, Game).
3. Press the translation shortcut — your translation appears in a floating HUD instantly!
